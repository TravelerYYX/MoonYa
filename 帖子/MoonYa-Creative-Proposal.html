01 / 创意介绍

项目概述

MoonYa 是一款面向 Windows 平台的端云协同 AI 桌面工作伴侣，深度融合多模型对话、全双工语音交互（Push-to-Talk + 实时语音对话）、Computer Use 桌面自动化、浏览器控制、本地文件系统操作、命令执行沙箱与多模态内容生成能力。

Problem

解决什么问题

当前主流 AI 助手仍停留在"文本问答"阶段，无法直接操作本地系统与工具链。知识工作者在浏览器、IDE、终端、文件系统之间频繁切换，导致工作流断裂、上下文丢失，大量时间浪费在低效的手动操作上。

Motivation

为什么做这个

开发与办公中的大量重复性操作可被抽象为"打开应用、读取信息、执行命令、整理输出"的组合。随着大模型能力成熟，自然语言有望成为连接人类意图与计算机执行的新接口，MoonYa 正是这一趋势下的工程实践。

Product

产品形态

基于 C# .NET 8 WPF + PHP 后端 + Python 微服务的端云协同架构，通过内嵌 Chromium 实现 Web UI 与本地能力的深度融合，打造具备系统级执行力的桌面 AI 伴侣。

Vision

核心理念

将 AI 从"信息生成器"升级为"任务执行器"。以自然语言与实时语音对话为统一交互入口，让 AI 具备感知屏幕、理解语音、操控桌面、调用浏览器与文件系统的能力，实现人机之间更高效、更自然的协同。

"让 AI 不只是回答，更是执行。"

— MoonYa 设计哲学

03 / 目标用户与痛点

为谁而做

MoonYa 面向需要高频使用计算机进行知识生产与信息处理的用户群体。

User 01

开发者 / 程序员

项目初始化、代码生成、依赖安装、Bug 定位、命令执行、文档查阅。

User 02

知识工作者

文档处理、信息检索、网页爬取、报告生成、邮件与日程管理。

User 03

学生 / 研究者

论文翻译与总结、代码学习、资料整理、公式讲解、笔记管理。

当前痛点

01

工具切换频繁

开发、办公、研究工作需要在多个应用与窗口间高频切换，导致工作流断裂、上下文丢失，严重消耗注意力资源。

02

AI 只能理解，无法执行

传统 AI 助手仅输出文本建议，无法直接调用系统工具或执行本地任务，"听懂"与"做到"之间存在明显断层。

03

交互效率受限

键盘输入在部分场景下不够自然，缺少低延迟、可打断、持续对话的语音交互能力，限制了 AI 的易用性。

基于 UIA 自动化与视觉分析，AI 可直接操控用户桌面：获取 UI 树（最大深度 6 层、2000 元素）、模拟鼠标键盘、执行拟人化拖拽、截图分析、应用启停与卸载。

UIA 自动化 视觉分析 鼠标键盘模拟 应用管理
04

本地文件系统操作

通过 HTTP API 提供读、写、删、移、复制、搜索、下载、解压缩等完整文件能力，支持 50+ 文件类型，具备路径白名单、系统目录保护与单文件大小限制等多重安全机制。

50+ 文件类型 路径白名单 目录遍历防护

在安全沙箱中执行 PowerShell / CMD / Python 脚本。采用高、中、低三级风险审核机制，内置 Python 3.11 沙箱（CPU 30 秒 / 内存 512MB 限制），并保留完整审计日志。

三级风险审核 Python 沙箱 审计日志

PuppeteerSharp 网页爬虫 双引擎搜索 域名白名单

四大 Agent mode_gate 四道安全防线
05 / 技术架构

系统设计与技术栈

MoonYa 采用端云协同的三层架构：C# .NET WPF 桌面客户端负责本地交互与系统调用；PHP 后端负责业务编排、数据持久化与第三方服务代理；Python 微服务负责 AI 推理、网页爬虫与网络搜索。

整体架构

L1

桌面客户端层

基于 .NET 8 WPF 构建，内嵌 CefSharp 147 加载 Web UI，实现原生应用与 Web 技术的深度融合。负责窗口管理、全局热键、语音采集、本地文件/命令执行、UI 自动化与系统调用。

L2

后端服务层

基于原生 PHP 实现，通过 MySQL + PDO 持久化用户、会话、配置与日志数据。提供 RESTful API、管理后台、文件上传下载、邮件通知与第三方 AI 服务代理。

L3

AI 微服务层

基于 Python 3 + aiohttp 构建独立服务，负责网页爬取、网络搜索、AI 工具调用等计算密集型任务，通过 SSE 流式推送进度与结果。

桌面端技术栈

运行时框架 .NET 8.0 WPF（Windows 10.0.19041+），启用 Windows Forms 互操作与不安全代码块，支持 x86 / x64 / ARM64 多平台构建。
Web 渲染引擎 CefSharp.Wpf.NETCore 147，内嵌 Chromium 加载 PHP 前端，实现原生应用与 Web UI 的统一体验。
浏览器自动化 PuppeteerSharp 20.0，支持页面导航、元素操作、截图、DOM 解析与浏览器上下文管理。
桌面自动化 Windows UIA（UI Automation）+ P/Invoke（user32 / kernel32），实现 UI 树遍历、窗口操控、鼠标键盘模拟与全局键盘钩子。
系统语音 System.Speech 10.0.9 提供本地 TTS 播报能力，作为云端语音合成的补充。
本地文件与命令 通过 C# IO API 与 Process 类实现文件读写、压缩解压、命令执行与软件安装调度。

后端技术栈

运行环境 PHP（原生实现，无重型框架），搭配 Nginx / Apache 运行，通过 .env 管理配置与密钥。
数据库 MySQL 8.x，使用 PDO + utf8mb4 进行数据持久化，存储用户、会话、聊天记录、配置、日志与审计信息。
邮件服务 PHPMailer 6.9，支持 SMTP 邮件发送，用于注册验证、通知与密码找回。
管理后台 原生 PHP + 自定义 admin-ui，支持系统提示词、工具配置、模型路由、用户与日志管理。
实时通信 SSE（Server-Sent Events）用于流式输出 AI 回复、爬虫进度与安装状态；WebSocket 代理用于阿里云 ASR 实时语音识别。
文件处理 提供文件上传、下载、预览、转码与临时沙箱目录管理，支持 50+ 文件类型。

Python 微服务技术栈

Web 框架 aiohttp 3.11+ 构建异步 HTTP 服务，提供 /crawl、/search、/download、/health 等端点。
网页爬虫 crawl4ai 0.8+ 实现完整网页抓取与资源本地化归档；Playwright 负责 Chromium 驱动与动态页面渲染。
网络搜索 自有 Python 搜索实现 + Kimi 官方搜索协议，双引擎互为备用，提升搜索成功率与覆盖度。
内容美化 jsbeautifier 处理爬取到的 HTML / JS / CSS 代码格式化，便于后续分析与展示。
任务调度 asyncio 协程 + 指数退避重试机制，保证后端依赖调用的高可用性。

前端 UI 技术栈

渲染方式 PHP 服务端渲染模块化组件（components / layouts / modules / styles），由 CefSharp 客户端加载呈现。
交互脚本 原生 JavaScript 模块化组织，涵盖消息列表、模式切换、Push-to-Talk、语音聊天、文件上传、下载与动态岛效果。
视频播放 HLS.js 实现社区与生成视频的流式播放。
样式方案 原生 CSS 模块化拆分 15+ 样式文件，覆盖布局、动画、响应式、代码高亮与主题组件。

第三方 AI 服务矩阵

大语言模型 Kimi（k2.5 / k2.6）、DeepSeek（V4 Flash / Pro）、智谱 GLM（4.5 / 4.7）、MiniMax（M2.7）、豆包（pro / lite）。
语音识别 阿里云 Fun-ASR，通过 WebSocket 实时流转写用户语音。
语音合成 MiniMax TTS，支持多音色语音合成与实时语音通话。
图像生成 CogView-3（智谱）与 MiniMax image-01 双引擎。
视频生成 CogVideoX-Flash（智谱）。
其他数据 天气、星座运势、文言文翻译等公开数据接口。

安全与治理

命令安全 高 / 中 / 低三级风险审核，正则 + 关键词双重匹配，危险操作强制用户确认。
文件安全 路径白名单、系统目录保护、单文件大小限制、目录遍历攻击防护。
网络安全 浏览器安全网关（trusted_domains 白名单）、API Key 环境变量管理、请求签名与审计日志。
沙箱隔离 Python 3.11 内置沙箱执行脚本，限制 CPU 时间（30 秒）与内存（512MB）。
06 / 价值与意义

为什么重要

MoonYa 的价值不仅在于功能整合，更在于重新定义了桌面场景下人机协作的方式。

Efficiency

效率提升

将编程开发、文档处理、信息检索等流程从"手动操作"升级为"自然语言驱动执行"，减少 40%-60% 的重复性步骤，让用户将认知资源集中在创造性工作上。

Accessibility

降低门槛

通过语音与自然语言指令，非技术用户也能完成复杂的系统操作（如软件安装、文件整理、环境配置），使 AI 成为普惠化的"桌面操作员"。

Exploration

技术探索

MoonYa 是国内较早将"Computer Use"理念落地到 Windows 桌面的实践之一，展示了 AI 从"对话助手"向"系统级协作者"演进的可行路径，具有较强的技术前瞻性与示范价值。
