MoonYa PTT 音效

从 script-3-push-to-talk.php 提取的 Web Audio API 提示音

1. 开始提示音 playStartTone()

按下 Ctrl+空格触发，扫频 880Hz → 1200Hz

osc.frequency: 880Hz → 1200Hz (exponentialRamp, 0.1s)
gain: 0.3 → 0.001 (exponentialRamp, 0.4s)

2. 结束提示音 playEndTone()

松开手触发，双音 660Hz + 880Hz（错开 150ms）

osc1: 660Hz × 0.3s
osc2: 880Hz × 0.3s（延迟 150ms）

3. 取消提示音 playCancelTone()

按 Esc 取消时触发，低频 200Hz 短促音

osc.frequency: 200Hz × 0.15s
gain: 0.2 → 0.001

原始来源：script-3-push-to-talk.php · 调用点：startRecording / __onAsrFinished / onCancel
