# 会话详情统计

模型左侧圆环在 Chat 和 Work 中打开同一个详情浮层。Token 用量、会话统计与上下文默认全部展开，打开浮层即可看到完整明细；各会话的手工折叠选择保存在浏览器现有 IndexedDB 历史中。关闭、重新打开和页面刷新后恢复该选择。浮层支持键盘、外部点击、Esc 和窄窗口。

## 数据与口径

`src/conversation-stats.mjs` 将实际模型调用、工具执行和有效上下文写入运行时数据目录下的 `statistics/conversations.jsonl`。用户和客户端会话标识共同确定统计归属，数据库会话标识作为别名，主 Work 执行会话按客户端会话汇总。子智能体使用独立的执行会话统计。开始和结束记录共享调用标识，结束替换开始；真实重试使用新的标识，SSE 回放不增加统计。

OpenAI 兼容协议的 `prompt_tokens` 包含缓存输入；从中扣除报告的缓存读取和缓存写入，得到未缓存输入。DeepSeek 显式命中、未命中字段优先。Anthropic 的输入不包含缓存读取与创建，因此分别相加得到输入总量。输出沿用供应商报告值，不额外叠加已包含的推理 Token。缺失缓存字段保持未知；不能用字符估算填充供应商用量。

总量为全部输入加输出。缓存命中率为缓存读取除以全部输入。模型用时累加每次实际请求的墙钟时间，TTFT 从发出请求到首个非空正文、推理或工具参数增量，排除身份和用量元数据。平均 TTFT 按有效样本算术平均；TPS 使用同时具备输出 Token 和解码时间的样本，计算输出总量除以解码总秒数。非流式返回不提供推测的 TTFT 或 TPS。

工具用时按各调用实际区间累加，审批与用户接管的等待区间单独扣除。并行调用分别累加，因此工具用时可以超过会话实际经过时间。调用取消或失败时保留已获取的用量和耗时；重启时尚未结算的开始记录保持不完整，不补造结束时间。

上下文来自实际有效请求、已生成的当前回复及保留的工具交互，草稿由前端另行估算。系统提示词、工具定义和消息均标注约数；模型长度来自已配置的模型能力。压缩替换当前上下文，累计用量不下降。模式、模型、窗口及 Work 执行会话分别筛选上下文，事件序号拒绝旧快照。旧会话没有请求记录时只显示可读取消息的局部估算，系统与工具构成显示暂不可用。

## 接口与恢复

浏览器发送请求增加 `client_chat_id`，通过登录鉴权的 `statistics.php` 读取统计；浏览器不能写入统计，也不能直接访问拒绝 `Origin` 的 Runtime。内部 `/v1/conversation-stats` 使用 GET 查询和 POST 写入，用户标识由 PHP 鉴权后填入。POST 可绑定数据库别名并提交单条后端采集记录。

查询包含 `client_chat_id`、单调日志 `revision`、`token_usage`、`timing`、当前 `context` 和 `completeness`。缺失指标为 `null`，完整性为 `complete`、`partial` 或 `unavailable`，同时提供调用数量与进行中状态。已确认的新会话可以显示 0；没有有效样本的 TTFT、TPS 和缓存命中率显示暂不可用。已有会话缺少早期记录时显示部分记录，历史缺失项不精确补算。

PHP 内置 Chat 在实际 curl 调用周围采集，自定义 Chat 与 Work 在模型适配器采集。两条链路推送 `session_statistics`；浮层打开及打开期间查询最新快照。前端只接受当前会话及不落后的 revision，上下文另行校验当前模型与执行会话。日志重启后重放，末尾残缺写入先备份再截断恢复；密钥、原始提示词和回复不进入统计日志。

## 验证

`node --test tests/conversation-stats.test.mjs` 覆盖供应商用量、实际流计时、失败与取消、重试、日志去重、数据库别名、损坏尾行、PHP 采集、真实 Runtime 组合、子智能体隔离和重启。`tests/loop.integration.test.mjs` 的审批用例验证长等待不计入工具时间。

后端 `node --test context_ring_test.js full_page_boot_test.js` 验证上下文竞争、完整页面启动、浮层折叠与恢复、键盘、外部点击、模型会话隔离及窄窗口，并生成 `artifacts/context-statistics/` 截图。截图数据来自测试模型适配器对本地模拟供应商的实际调用，不是产品内置示例值。

源码变更需要重新构建并重启客户端，已启动的 Runtime 不会热更新。
